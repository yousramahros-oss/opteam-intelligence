# Références visuelles (model sheets)

Déposer ici les planches (les images servent de **référence à joindre dans Veo**).

Nommage suggéré :
```
grognon.png      giovanna.png      sanplerien.png
giovanni.png     giovannia.png
decors.png       objets.png        limousine.png
```

**Astuce Veo :** pour chaque perso, garder aussi une version **recadrée** (une seule pose
de face, fond neutre, sans le texte de la planche) → `grognon_face.png`, etc.
Veo suit beaucoup mieux une image de référence propre que la planche entière.
